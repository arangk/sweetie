# 갤러리 개수와 RSVP 입력 항목 설정

## 갤러리

```js
galleryCount: 4,
```

- gallery 목록 중 앞에서부터 정상 로딩된 사진을 최대 4장 표시.
- 0이면 사진을 숨김. 항목을 생략하면 정상 사진 모두 표시.
- 사진 부족 또는 파일 오류 시 있는 정상 사진만 표시.
- 사진을 더 쓰려면 gallery 목록에 src/caption 항목도 추가.
- 6장까지 기존 콜라주 유지, 7장 이상은 아래로 확장하는 콜라주.
- 확대 보기의 번호와 이전/다음은 실제 표시 사진 기준.

## 참석 입력 항목

```js
rsvpFields: ['참석 여부'],
// 또는
rsvpFields: ['참석 여부', '전세버스 이용 여부'],
```

선택 가능한 항목: 하객 구분, 참석 여부, 식사 여부, 전세버스 이용 여부, 성함, 연락처, 동행인 성함, 동행인 수.

- 한글 띄어쓰기 차이는 허용.
- 목록을 생략하면 기존 모든 항목 표시, []이면 모든 항목 숨기고 제출 버튼 비활성.
- 목록에 없는 항목은 숨기고 입력을 disabled 처리하므로 필수 검사를 방해하지 않음.
- 참석 여부가 있는 폼에서 불참 선택 시 식사/버스/동행인 항목도 숨김.
- 참석 여부를 사용하지 않으면 버스 등 지정한 항목을 그대로 사용.
- 항목 순서는 기존 기본 폼 순서를 유지함.
- 사이트 내부 미리보기 폼 설정이며 구글폼의 질문·응답 저장 설정은 자동 변경하지 않음.

## 브라우저 검사

Chromium 390×844, reduced-motion 조건으로 확인.

- 갤러리 0/1/2/4/6/9/12장과 확대 보기 전체 순환.
- 10장을 요청했지만 6장만 있는 경우, 빈 파일·없는 파일을 건너뛰어 3장 표시, 개수 옵션 생략.
- 참석 여부만, 참석+버스(띄어쓰기 없음), 버스만, 빈 목록.
- 선택하지 않은 필드의 disabled와 유효성 검사, 불참→참석 왕복 분기.
- 외부 구글폼 저장 연동은 이 변경에서 추가하지 않음.
