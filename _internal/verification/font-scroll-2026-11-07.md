# 폰트 첫 표시와 스크롤 응답 개선

## 변경

- HTML의 타이틀 글자를 처음에는 비워 기본 글꼴 문구가 먼저 노출되지 않도록 함. 접근성 이름은 유지.
- 영문 Parisienne WOFF2 약 28KB는 HTML에 포함. 외부 폰트 요청을 기다리지 않음.
- 타이틀 준비는 손글씨·한글 본문 폰트 로딩과 분리.
- 기본 초대 문구 글리프와 영문/숫자는 약 20KB 손글씨 파일로 제공. 나머지 글리프는 기존 2.95MB 파일을 unicode-range로 보완.
- config.greeting을 다른 문구로 바꿔도 원본의 나머지 글리프 사용 가능. 실제 설정 문구의 준비를 기다린 후 타자기 시작.
- Google Fonts CSS import 제거. 사용하던 Cormorant Garamond도 공식 Google Fonts 원본에서 로컬 WOFF2로 변환하고 OFL 포함.
- JS/CSS URL에 버전 키를 붙여 이전 캐시와 구분.
- 스크롤 스냅을 mandatory에서 proximity로 완화. 근처 섹션은 정렬하지만 모든 제스처를 강제로 끊지는 않음.
- 일반 등장 효과 0.28초, 지연 최대 0.14초로 단축. 갤러리는 0.4초/장, 사이 간격 0.08초.
- 전역 non-passive gesture/multitouch 핸들러 제거. 확대 방지는 viewport와 touch-action으로 유지.
- 종이 질감은 동적 필터 대신 정적 SVG 타일로 변경. 화면 밖 반복 애니메이션 일시정지.

## 검증

Chromium 로컬 서버에서 확인.

- 기본 문구에서는 20KB 손글씨 파일만 요청, 원본 2.95MB 손글씨 요청 없음.
- Google Fonts 외부 요청 없음.
- app.js를 1.2초 늦춰도 초기 타이틀 글자는 노출되지 않음.
- 타이틀 폰트 준비 후 타자기와 초대글 타자기 정상.
- 다른 한국어 문구에서는 원본 보완 폰트 요청 및 표시 정상.
- 스크롤 입력 후 0.7초 시점에 다음 섹션 정렬 확인. 실제 iOS Safari의 성능 실측과는 구분.
- 사진 0/1/2/4/6/9/12장 및 RSVP 선택 옵션 회귀 검사 통과.

## 배포 확인 범위

GitHub 푸시는 수행하지만 Cloudflare 대시보드 접근 권한은 없다. 공개 workers.dev 주소도 현재 환경의 네트워크 정책에서 403으로 차단돼 실제 배포 반영/자동 빌드 여부를 단정하지 않는다. 사용자가 대시보드에서 이번 커밋의 새 빌드가 자동 생성됐는지 확인해야 한다. HTML에는 app-version=2026-11-07-font-scroll을 남겨 반영 버전을 식별한다.

사이트가 이미 정상 노출됐다는 사용자 확인 후, 준비 중이던 새 wrangler.jsonc/.assetsignore는 적용하지 않고 기존 Cloudflare 배포 설정을 유지했다.
