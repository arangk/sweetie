# 날짜 설정 자동 반영 검증

사용자가 main에서 바꾼 2027-03-13T12:30:00+09:00을 fetch/fast-forward로 보존한 뒤 수정했다.

## 수정

- index.html의 고정 예식일·시간 제거.
- 첫 화면, 날짜 큰 숫자, 연월, 달력, 장소 위 시간, 참석 안내를 config.date에서 계산.
- 달력의 시작 요일, 그 달 일수, 예식일 강조를 자동 계산.
- 한국 시간 기준으로 표기하며 해외에서 보더라도 날짜가 달라지지 않음.
- D-day는 한국의 날짜 단위로 계산. 당일 예식 시작 전에도 1일 남음으로 표시하지 않음.
- 열린 페이지의 자정 경과와 탭 복귀를 고려해 D-day 갱신.
- 날짜 형식 오류·존재하지 않는 날짜는 확인 안내를 표시하며 다른 기능은 중단하지 않음.

## 브라우저 확인

Chromium의 기기 시간대를 America/Los_Angeles로 바꿔 검사했다.

- 사용자 설정 2027년 3월 13일 토요일 오후 12시 30분.
- 윤년 2028년 2월 29일 화요일 오후 1시 5분.
- 2027년 5월 31일 월요일 오전 12시, 6주 달력.
- 2026년 11월 1일 일요일 오후 12시, 일요일에 시작하는 달.
- 한국 3월 12일 23:59:59에는 1일 남음, 3월 13일 00:00:01에는 오늘은 결혼식 날.
- 빈 값, 잘못된 문자열, 2027년 2월 30일은 오류 안내.
- 320×664에서 5주·6주 달력 화면 높이 확인.

## 배포 상태 구분

사용자가 제공한 Netlify 화면은 배포용 크레딧 제한으로 production deploy가 중지되고 config 변경 배포가 skipped된 상태였다. 코드와 GitHub 커밋 완료가 공개 사이트 반영을 의미하지 않는다. 크레딧/배포 재개 또는 다른 호스팅 연결이 별도로 필요하다. 무료 플랜을 무제한 배포로 소개하지 않는다.
