# 손글씨 및 페이지 이동 재검증

이 변경은 font-scroll-2026-11-07.md의 네이티브 스크롤 보정 및 손글씨 분할 방식을 대체합니다.

- 손글씨는 원본 NanumDaughterToMom.woff2 하나로 로드합니다. 폰트 로딩 대기 시간이 지나도 다른 글꼴을 먼저 표시하지 않습니다.
- 섹션 이동은 단일 transform 트랙에서 480ms 동안 처리합니다. 도착 후 등장 효과와 타자기를 시작하며 돌아오면 다시 실행합니다.
- 휠 관성 입력은 한 번의 이동으로 묶습니다. 모바일 세로 스와이프와 키보드 PageUp/PageDown도 지원합니다.
- 내용이 화면보다 길면 해당 섹션 내부에서 먼저 스크롤합니다. 팝업의 입력과 스크롤에는 개입하지 않습니다.

Chromium 자동 검증 결과:

- 연속 휠 10회 입력이 한 섹션으로만 이동함.
- 다음 이동, 역방향 이동, 모바일 터치 스와이프 후 활성 섹션의 top이 0임.
- 화면 크기 변경 후 활성 섹션 정렬 유지.
- 손글씨 다운로드를 5.5초 지연: 대기 중 문구 숨김, 원본 로드 후 표시.
- 320×568, 393×752, 430×932에서 섹션 높이 및 표지 하단 잘림 확인.
- 하단 참석 버튼에서 입력 폼 직접 열기/닫기 정상.
- 사진 12장 구성에서 내부 스크롤 정상.
- 브라우저 JavaScript 오류 없음. 실제 iPhone Safari 검증은 수행하지 않음.
