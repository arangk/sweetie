# 1. 사진·정보와 개인정보 준비

작업하기 전에 아래 내용을 한곳에 모아 주세요. 빠진 정보가 있으면 예시값으로 남겨둘 수 있지만 하객에게 공유하기 전에는 반드시 교체해야 합니다.

## 준비물

- PC와 휴대폰
- 본인이 접근할 수 있는 GitHub·Netlify·Google 계정
- 갤러리 사진 6장
- 카드에 넣을 컬러 일러스트와 초대글 배경용 흑백 일러스트
- 약도 이미지 또는 예식장 공식 약도

현재 디자인은 사진 6장을 기준으로 합니다. 사진 수를 바꾸는 것은 심화 수정에 해당합니다. 일러스트가 없다면 사용 권한이 있는 사진으로 대체하거나 심화 코스의 AI 일러스트 작업을 이용할 수 있습니다. AI 이미지 생성은 이 기본 코스의 필수 과정이 아닙니다.

## 사진을 올리기 전에

1. 사진에 나온 사람의 공개 동의를 확인합니다.
2. 배포용 사본을 만들고 원본은 별도로 보관합니다.
3. 웹에서 보기 적절한 크기와 용량으로 줄입니다. 긴 변 1,200~1,600px 정도를 출발점으로 삼고 실제 휴대폰에서 선명도를 확인하세요.
4. EXIF 위치정보를 제거합니다. 사용한 도구에서 제거 여부를 확인하세요. 확장자를 바꾸는 것만으로 제거되지 않습니다.
5. 사진 파일명은 `gallery-01.webp`처럼 단순하게 정리합니다. 사진 내용을 늘이거나 찌그러뜨리지 않습니다.

### AI에게 요청할 때

```text
첨부한 사진의 배포용 사본을 만들어줘.
인물·구도·색을 바꾸지 말고 원본 비율을 유지해 웹용으로 용량을 줄여줘.
EXIF 위치정보를 제거하고 파일별 크기·용량과 실제 확인한 메타데이터 제거 결과를 알려줘.
원본 파일은 덮어쓰지 마.
파일을 읽거나 수정할 수 없는 환경이면 못 했다고 말해줘.
확인하지 못한 것을 확인했다고 말하지 마.
```

AI가 파일을 직접 처리할 수 없는 환경이라면 이미지 편집 도구의 웹용 내보내기 기능을 사용하세요.

## 링크를 아는 사람은 볼 수 있어요

GitHub 저장소를 비공개로 해도 Netlify 사이트를 공개하면 청첩장은 열람할 수 있습니다. 검색 제외 설정도 비밀번호와 같은 접근 제한은 아닙니다.

계좌를 접어두거나 전화번호를 숨겨도 사이트 파일에 포함된 정보는 확인할 수 있습니다. 신혼집 주소·불필요한 연락처·하객 응답을 페이지에 넣지 마세요. 관리자 비밀번호, API 키, 신분증, `.env` 파일도 올리지 않습니다.
