# 운영자용: 노션 자료 공개 전 체크리스트

이 문서는 독자용 자료와 분리해 비공개로 관리합니다. 현재 문서는 초안이며 공개용 안내에는 미완성 기능이나 검증되지 않은 버튼명을 완성된 사실처럼 쓰지 않습니다.

## 정보 구조 결정

- 제공물: 수정 가능한 청첩장 템플릿 + 사진/정보 교체 프롬프트 + RSVP/배포 가이드.
- 기본 대상: 처음부터 디자인하기보다 완성된 틀에 내 자료를 넣고 싶은 비개발자 예비부부.
- 기본 경로: 내 비공개 GitHub 사본 → 정보 수정 → 구글폼/구글시트 → Netlify Git 연동 → 최종 점검.
- 심화 경로: 기본 완성 후 AI로 스타일/일러스트/새 디자인 수정.
- 기본 코스에서 여러 AI 서비스와 배포 방법을 병렬로 소개하지 않는다. 실제로 검증한 작업 환경 하나를 대표 경로로 확정한다.
- 릴스 기획·게시 작업은 이번 자료 범위에서 제외한다.

## 공개를 막는 현재 기술 항목

### 날짜·정보 수정 범위

- [ ] config.js 한 파일에서 예식일·시간·이름을 바꾸면 모든 화면이 갱신되도록 정리.
- [ ] 현재 HTML과 JS의 예시 날짜·시간, 고정된 달력의 28일/시작요일/27일 강조를 실제 설정값에서 계산하도록 변경.
- [ ] 한국 시간의 자정 기준으로 D-day가 맞는지 테스트. 예식 시각과 남은 날짜 수를 혼동하지 않음.
- [ ] 신랑·신부 정보가 메인·팝업·폼·메타정보에서 일치하는지 확인.
- [ ] 카드·흑백 일러스트·하단 배경·약도도 명확한 설정 경로로 교체 가능하게 정리.

### 실제 RSVP 경로

- [ ] 예비부부 소유의 실제 구글폼 생성.
- [ ] 기본 배포본은 구글폼 입력 경로로 확정. 내부 폼은 제거하거나 제작 미리보기로 분리.
- [ ] 입력을 두 번 요구하지 않음. 내부 폼 → 구글폼 미리 채우기를 택하면 각 항목 매핑과 실제 저장까지 검증.
- [ ] 구글시트 저장 확인, 외부 응답 허용 설정 확인, 불참 분기 검증.
- [ ] 개인정보 안내·보관 기간·예식 후 삭제 안내 준비.
- [ ] 전세버스·연락처·동행인 이름의 필요 여부를 기본 자료에서 강제하지 않음.

### 배포용 템플릿

- [ ] 현재 개발 저장소와 별개로 공유할 버전을 확정. 자동으로 현재 비공개 저장소를 공개하지 않음.
- [ ] 실제 ‘템플릿에서 새 저장소 생성 → Private 선택’ 경로를 테스트. 지원되지 않는 경우 검증된 대체 복사 경로 안내.
- [ ] 코드·폰트·이미지의 이용·수정·재배포 범위와 금지 범위를 확정.
- [ ] 업로드 폰트를 템플릿에 재배포할 수 있는지 원래 배포처의 이용 조건 확인. ZIP에 글꼴만 있으면 허용을 추정하지 않음.
- [ ] 예시 인물 사진이 AI 생성임을 안내. 제3자 실제 사진·개인정보가 템플릿/기록에 섞이지 않도록 확인.
- [ ] 갤러리 예시 사진을 독자가 바꿔야 하는지, 그대로 사용 가능하게 제공할지 결정.
- [ ] 사용하지 않는 디자인 시안·옛 폰트·작업 문서를 배포용 폴더에서 정리.
- [ ] Git 과거 기록과 공개 배포에도 민감 정보가 없는지 확인.
- [ ] README에 실제 최신 파일 구조와 수정 경로 안내. DEVELOPMENT.md는 변경 이력 누적으로 옛 설명이 있어 독자 가이드로 직접 사용하지 않음.

### 공유와 운영

- [ ] 실제 공개 URL과 OG 이미지·제목·설명 준비.
- [ ] 카카오톡에서 실물 미리보기 테스트. 개인화 ?to=이름은 현재 미구현이며 제공 기능으로 소개하지 않음.
- [ ] 폰트·사진을 처음 로딩하는 느린 환경과 iOS Safari·Android에서 확인.
- [ ] 스크롤 스냅·모션·확대 정책을 포함해 접근성 검토. 현재 페이지 확대를 막고 있으므로 독자용 배포에서 유지할지 재검토.
- [ ] 문의 창구와 개별 지원 범위 확정.
- [ ] 무료 서비스의 요금제·한도·메뉴명 확인일 기록.

## 필요한 캡처 목록

| 페이지 | 필요한 캡처 |
|---|---|
| 시작하기 | 최신 청첩장 첫 화면, 카드 팝업, 갤러리, 예식일 |
| 준비물 | 내 정보 준비표, 사진 사본/메타데이터 확인 예시 |
| 템플릿 복사 | 내 계정으로 복사, Private, 주요 파일 목록 |
| 정보 수정 | 실제 선택한 AI 환경의 저장소 연결·첨부·변경 내역·푸시 완료 |
| RSVP | 폼 질문, 참석/불참 분기, 응답자 접근, 시트 연결, 응답 저장 |
| 배포 | Netlify Git 연결, 루트 게시 설정, 최신 커밋 Published, 기본 URL |
| 공유 | 시크릿 창 정상 접근, 카카오톡 OG 미리보기 |
| FAQ | README만 게시한 404 예시, 이전 커밋 Published, 접근 제한 |
| 정리 | 응답 수집 종료, 공개 해제·배포 삭제, 응답 사본 정리 |

캡처는 가상 이름과 정보를 사용하고 계정 이메일·토큰·하객 응답을 가린다. 다른 사람의 릴스·공유자료 화면을 우리 안내 화면처럼 사용하지 않는다.

## 처음 보는 사람 테스트

개발 과정을 보지 않은 비개발자 1명에게 자료와 템플릿만 제공한다.

1. 어디에서 멈췄는지, 어떤 단어를 몰랐는지 기록한다.
2. 설명 없이 개입한 횟수와 이유를 기록한다.
3. 본인 사진·정보 변경 → 공개 링크 → 테스트 RSVP 저장까지 완주하는지 본다.
4. 막힌 지점의 설명·캡처를 보완한 뒤 같은 경로를 재검증한다.
5. 초안에 남은 대괄호 링크와 편집 메모를 제거한다.

완주 테스트 전에는 ‘누구나 몇 분 만에’, ‘사진만 바꾸면 끝’처럼 과정이 생략된 약속을 하지 않는다.

## Notion 배치

- 최상위 홈: 00-시작하기의 소개, 결과 예시, 준비·비용, 단계별 링크, 이용 안내.
- 하위 페이지: 01~09를 각각 한 페이지로 배치.
- 운영자 문서: 이 파일은 공개 페이지 트리 밖에 둠.
- 단계별 페이지는 목적 → 할 일 → 복사 요청문 → 캡처 → 완료 기준 흐름을 유지.
- 긴 FAQ는 나중에 토글로 정리하고 복사 요청문은 코드블록으로 배치.
- 초기에는 검색 엔진 색인을 끄고 필요한 대상에게 링크로 안내. 복제 허용 여부는 제공 방식에 맞춰 결정.
- 노션 자료가 비공개여도 그 안의 Netlify 예시는 별도 공개 설정이므로 접근 범위를 각각 확인.
- 정확한 공유·색인·복제 메뉴 위치는 실제 노션 화면에서 확인하고 문서에 반영.
