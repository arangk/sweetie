# 8. 예식 후 정리하기

사이트를 안 쓴다고 사진과 하객 응답이 자동으로 삭제되지는 않습니다. 사전에 정한 기간에 정리하세요.

## 응답 정리

1. 필요한 응답 자료만 안전하게 백업합니다.
2. 구글폼의 응답 수집을 종료합니다.
3. 보관 기간이 끝나면 폼·연결 시트·다운로드한 사본의 개인정보를 삭제합니다.
4. 함께 관리한 사람이 있다면 공유 사본과 권한도 확인합니다.

폼만 삭제해도 시트나 내려받은 파일은 남을 수 있습니다.

## 사이트·사진 정리

1. 청첩장을 비공개로 바꾸거나 배포를 종료합니다.
2. 기본 주소뿐 아니라 과거 배포 주소의 접근 상태도 확인합니다.
3. Netlify의 남은 배포·이미지와 GitHub 저장소·수정 기록의 개인정보를 확인합니다.
4. 공개 저장소였다면 다른 사람이 만든 사본까지 회수할 수 없다는 점을 염두에 둡니다.
5. 자료를 보존하고 싶다면 개인정보를 뺀 버전을 따로 만듭니다.

현재 파일에서 사진을 지웠다고 과거 Git 기록과 배포본에서까지 지워진 것은 아닙니다. 삭제 범위를 확인하고, 필요한 경우 서비스의 공식 삭제 절차를 이용하세요.

## 마지막 확인

- [ ] 참석 응답 수집을 종료했다.
- [ ] 정한 기한에 응답과 사본을 정리했다.
- [ ] 사이트와 과거 배포의 공개 상태를 확인했다.
- [ ] 사진·연락처·계좌가 남은 위치를 확인했다.
- [ ] 도메인·유료 옵션이 있다면 자동 결제도 확인했다.
