# 4. 참석 응답 폼 만들고 연결하기

RSVP는 하객의 참석 여부를 미리 받는 기능입니다. 버튼과 입력 화면이 보이는 것만으로 응답이 저장되지는 않습니다.

이 코스에서는 **하객이 구글폼에 입력 → 예비부부가 구글시트에서 확인**하는 방식을 사용합니다.

> 현재 예시 사이트의 내부 입력폼은 미리보기입니다. 실제 응답 저장과 연결되지 않았습니다. 자료 공개 전에 내부 미리보기를 거치지 않고 구글폼으로 이동하는 경로를 완성·검증해야 합니다. 이미 입력한 내용을 구글폼에 자동으로 넘기는 기능도 현재는 없습니다.

## 1단계: 내 소유의 구글폼 만들기

Google 계정에 로그인하고 새 설문지를 만듭니다. 제목은 ‘서준·지우 결혼식 참석 안내’처럼 알아보기 쉽게 씁니다. 아래 설명을 내 정보로 바꿔 넣으세요.

```text
저희의 시작을 함께해 주셔서 감사합니다.
더 편안하게 모실 수 있도록 참석 여부를 알려주세요.

예식일: [날짜와 시간]
장소: [예식장·홀]
응답 마감: [날짜]
응답 변경 문의: [담당자 연락 방법]
```

[캡처: 새 폼 생성 → 제목·설명 입력]

## 2단계: 필요한 질문만 추가

| 질문 | 추천 형식 | 필수 여부 |
|---|---|---|
| 어느 측 하객인가요? | 신랑측 / 신부측 단일 선택 | 필수 |
| 참석하시나요? | 참석 / 불참 단일 선택 | 필수 |
| 성함 | 짧은 답변 | 필수 |
| 식사 여부 | 식사함 / 안 함 / 미정 | 참석자에게만 |
| 동행인 수(본인 제외) | 숫자, 0 이상 | 참석자에게만 |
| 연락처 | 짧은 답변 | 꼭 필요할 때만 |
| 동행인 성함 | 짧은 답변 | 꼭 필요할 때만 |
| 전세버스 탑승 여부 | 탑승 / 미탑승 | 버스를 운영할 때만 |

불참자에게 식사·버스 질문을 강제로 입력시키지 않도록 섹션을 나누고 답변에 따른 이동을 설정합니다. 정확한 메뉴 위치는 최신 화면 캡처로 안내합니다.

내부 입력폼 예시는 연락처·버스 질문을 포함하지만, 구글폼에 그대로 모두 넣을 필요는 없습니다. 실제 운영에 필요한 정보만 받으세요.

## 3단계: 개인정보 안내와 동의

다음은 채워 넣을 항목의 예시이며, 그대로 게시하는 완성 약관은 아닙니다. 실제 수집 항목과 보관 방식에 맞춰 작성하세요.

```text
수집·이용 목적: 결혼식 참석 인원 및 [식사/버스 등 실제 목적] 확인
수집 항목: [실제로 받는 항목만 작성]
보관 기간: [명확한 종료일 또는 기간]
관리 담당 및 문의: [연락 방법]
동의 거부 안내: [동의하지 않을 때 적용할 대체 연락 방법 등]
```

Google 서비스를 통한 처리와 보관 위치 등 필요한 고지 사항도 실제 이용 조건에 맞춰 확인하세요. 동행인의 개인정보를 받는다면 전달하는 사람이 해당 동행인에게 알리고 동의를 얻도록 안내하세요. 이름과 연락처를 불필요하게 공개하지 않습니다.

## 4단계: 구글시트 연결

1. 폼의 응답 관리 화면을 엽니다.
2. 스프레드시트로 연결하는 기능을 선택합니다.
3. 내 계정에 새 응답 시트를 만듭니다.
4. 접근 권한은 응답을 관리할 사람에게만 부여합니다.
5. 응답 결과를 공개하는 설정이 켜져 있지 않은지 확인합니다.

[캡처: 응답 탭 → 시트 연결 → 테스트 응답 행]

## 5단계: 응답자용 링크 확인

폼의 공유 기능에서 **응답하는 사람에게 제공할 링크**를 복사합니다. 편집 링크나 응답 시트 주소를 청첩장에 넣지 마세요.

시크릿 창에서 링크를 엽니다. 로그인 없이 응답받을 계획이라면 실제로 로그인 요구가 없는지 확인해야 합니다. 조직 내부 제한·파일 업로드 질문 등 일부 설정은 로그인을 요구할 수 있습니다. 설정 이름만 보고 판단하지 마세요.

## 6단계: 청첩장에 연결

응답자 링크를 AI에게 전달합니다.

```text
청첩장의 실제 참석 응답 경로를 이 구글폼으로 연결해줘.
응답자용 링크: [링크]

메인 카드의 참석 안내 버튼과 하단 참석 버튼에서 구글폼을 열 수 있게 해줘.
사이트 내부의 미리보기 입력폼을 먼저 작성하게 해서 같은 정보를 두 번 입력하지 않도록 해줘.
내부 입력값을 자동 전송하는 연동이 없다면 있다고 말하지 마.
실제 제출은 구글폼에서 이루어진다고 사용자가 알 수 있게 해줘.
그 외 디자인은 유지하고 수정 후 확인한 것과 미확인 항목을 구분해줘.
```

설정 파일에서는 `rsvpUrl`에 응답자 링크를 넣습니다. 현재 예시 구현은 URL을 넣는 것만으로 내부 미리보기 단계가 없어지지는 않으므로 위 경로 수정도 필요합니다.

## 7단계: 전달과 저장을 끝까지 테스트

- [ ] 청첩장 메인 카드에서 응답 폼으로 갈 수 있다.
- [ ] 하단 버튼에서도 응답 폼으로 갈 수 있다.
- [ ] 시크릿 창과 실제 휴대폰에서 필요한 접근 범위로 열린다.
- [ ] 가짜 이름으로 참석·불참을 각각 제출했다.
- [ ] 구글폼에 제출 완료 화면이 나온다.
- [ ] 내 구글시트에 두 응답이 실제로 저장됐다.
- [ ] 불참자는 불필요한 질문을 건너뛴다.
- [ ] 응답 변경 방법과 문의처를 안내했다.
- [ ] 테스트 응답을 삭제했다.

이 항목을 모두 확인한 뒤 참석 기능이 작동한다고 안내하세요. 실제 하객 개인정보로 테스트하지 않습니다.
