# 7. 막혔을 때 확인하기

## 사이트가 Not Found / 404로 떠요

GitHub를 Public으로 바꾸기 전에 아래 순서로 확인하세요.

1. 저장소에 README만 있는 것은 아닌가요?
2. 저장소 루트에 `index.html`이 있나요?
3. 수정 파일을 커밋·푸시했나요?
4. Netlify가 같은 저장소·브랜치를 읽고 있나요?
5. Publish directory가 실제 파일 위치와 같나요?
6. 최신 커밋에 Published가 표시되나요?
7. 이전 배포 고정 주소를 보고 있지는 않나요?

## 사이트가 Netlify 로그인을 요구해요

시크릿 창에서도 같은지 확인하고 Netlify의 사이트 접근 보호·공개 설정을 확인합니다. GitHub 비공개 저장소를 공개로 바꾸는 것으로 해결하려 하지 마세요.

## 수정했는데 예전 화면이에요

로컬/AI 작업 공간의 파일, GitHub 최신 커밋, Netlify 현재 게시 커밋을 순서대로 비교합니다. 그다음 기본 주소를 새로고침합니다. 예전 고정 배포 URL은 새 버전으로 바뀌지 않습니다.

## 사진이 안 나와요

파일이 실제로 업로드됐는지, 파일명 대소문자와 경로·확장자가 일치하는지 확인합니다. PC의 파일 경로를 넣으면 다른 사람에게 보이지 않습니다.

AI 채팅에서 보이는 이미지가 자동으로 저장소에 들어가는 것은 아닙니다. 생성 파일을 실제 배포 폴더에 저장했는지 확인하세요.

## 손글씨가 바뀌거나 처음에 기본 폰트가 보여요

폰트 파일의 경로·로딩 상태를 확인합니다. 현재 예시는 폰트 미리 불러오기와 로딩 후 타자기 시작을 적용했습니다. 다른 폰트로 바꾸면 파일 경로·선언·preload도 함께 수정해야 합니다.

폰트 사용·재배포 권한은 글꼴마다 다릅니다. 내려받았다는 이유만으로 템플릿에 번들할 수 있다고 판단하지 마세요.

## 화면이 잘리거나 스크롤이 답답해요

기기, 브라우저, 주소창이 보이는지, 스크롤 방향을 함께 기록합니다. 글자 확대 설정과 펼친 계좌·교통 안내 상태도 확인하세요. 문구가 길어졌다면 한 화면에 억지로 넣기보다 글을 줄이거나 콘텐츠 높이를 허용해야 할 수 있습니다.

## 참석 입력은 했는데 전달이 안 돼요

현재 내부 폼은 미리보기입니다. 실제 구글폼 연결과 응답 저장 테스트가 필요합니다. 링크만 연결한 상태에서는 내부 입력값이 자동 전달되지 않습니다. 같은 내용을 두 번 입력하게 만들지 않도록 실제 배포 경로를 정리하세요.

제출 완료 화면과 구글폼 응답 탭·연결 시트를 확인하기 전에는 전달됐다고 간주하지 않습니다.

## AI에게 오류를 물어볼 때

```text
모바일 청첩장에서 아래 문제가 생겼어. 원인을 확인하고 필요한 부분만 수정해줘.

사이트 주소:
기대했던 동작:
실제 동작:
기기 / 브라우저:
재현 순서:
오류 메시지:
최근 수정 내용:

기존 디자인과 정상 동작은 유지해줘.
파일·로그를 읽지 못하면 읽었다고 하지 마.
추측과 확인된 원인을 구분해줘.
수정 후 실제 확인한 범위와 미확인 범위를 알려줘.
```

스크린샷과 로그에서 전화번호·계좌·하객 이름·관리자 키는 가립니다. 오류 메시지는 내용을 바꾸지 말고 필요한 부분만 그대로 전달하세요.
