# 심화. AI로 내 취향에 맞게 수정하기

기본 코스를 완성한 뒤 한 번에 한 가지씩 바꿉니다. 지금 작동하는 커밋을 기록하고 화면을 캡처해두면 돌아오기 쉽습니다.

## 수정 요청은 세 부분으로

1. 유지할 것
2. 바꿀 것
3. 확인할 것

```text
현재 청첩장에서 아래 항목만 수정해줘.

[유지]
섹션 순서, 사진, 참석 폼 연결, 지도·계좌 복사, 모바일 대응은 유지.

[변경]
[예: 버튼 모서리만 조금 둥글게 / 초대 문구만 크게 / 배경색만 변경]

[확인]
작은 화면에서 글자나 사진이 잘리지 않는지 확인해줘.
모바일 터치와 PC 클릭을 확인하고, 모션을 줄인 설정에서도 사용할 수 있게 해줘.
확인한 것과 확인하지 못한 것을 구분해줘.
```

‘전체적으로 더 예쁘게’보다 변경 범위를 구체적으로 적으면 반복 수정이 줄어듭니다. 서로 다른 기기의 캡처가 있으면 함께 전달하세요.

## 사진을 일러스트로 바꾸고 싶다면

권한이 있는 사진을 사용하고 사진 속 인물에게 AI 서비스 전달과 공개에 대한 동의를 받습니다. 이용하는 도구가 이미지 편집을 지원하는지 확인하세요.

```text
첨부 사진을 모바일 청첩장에 쓸 [수채화/연필화]로 변환해줘.
두 사람의 얼굴 특징·옷·포즈·구도는 최대한 유지해줘.
글자·로고·장식은 새로 추가하지 마.
카드에 쓸 세로 이미지이며 인물의 손과 발이 잘리지 않게 해줘.
얼굴·손·소품이 달라질 수 있으니 결과는 내가 검수할게.
첨부 사진을 볼 수 없으면 먼저 알려줘.
```

생성한 결과는 원본과 완전히 같지 않을 수 있습니다. 얼굴·손·반지·꽃·간판을 직접 확인하세요. 결과 이미지가 채팅에 보이지 않으면 생성 파일 자체가 있는지 확인하고, 파일을 배포 폴더에 저장해야 사이트에 나타납니다.

## 처음부터 새 디자인을 만들고 싶다면

기본 템플릿과 별도 사본에서 진행하세요. 참고 자료는 분위기를 설명하는 용도로 쓰고 다른 작품의 문구·사진·구도를 그대로 복제하지 않습니다.

디자인 시안 → 한 화면 구현 → 모바일 확인 → 나머지 섹션 확장 → 실제 정보·폼 연결 → 배포 테스트 순서로 작업하세요. 처음부터 모든 기능을 한 번에 만들라고 요청하지 않는 편이 수정 범위를 관리하기 쉽습니다.
