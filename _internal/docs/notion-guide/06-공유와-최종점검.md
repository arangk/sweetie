# 6. 공유 전 최종 점검

PC에서 열리는 것과 하객이 휴대폰·카카오톡으로 보는 것은 다를 수 있습니다. 아래를 직접 확인한 뒤 공유하세요.

## 정보

- [ ] 이름·예식일·요일·시간·예식장·홀·주소가 정확하다.
- [ ] 카드, 달력, 참석 안내의 날짜·시간이 일치한다.
- [ ] 예시 이름과 가상 계좌가 남아 있지 않다.
- [ ] 교통·주차·지도 링크가 실제 장소에 맞다.

## 휴대폰 동작

- [ ] 첫 화면 아래가 잘리지 않는다.
- [ ] 주소창이 접히고 펼쳐져도 화면이 어색하지 않다.
- [ ] 위→아래와 아래→위로 모두 스크롤해 봤다.
- [ ] 타이틀·초대글이 최종 폰트로 표시된다.
- [ ] 카드에서 참석 안내가 열린다.
- [ ] 갤러리 사진 6장을 모두 열 수 있다.
- [ ] 확대 보기의 넘기기·닫기가 작동한다.
- [ ] 계좌와 주소가 실제로 복사된다.
- [ ] 사진이 찌그러지지 않고 얼굴이 잘리지 않는다.
- [ ] iPhone과 Android 등 서로 다른 기기에서도 확인했다.

가능한 기기에서만 확인했다면 확인하지 못한 기기는 미확인으로 남깁니다. 한 기기 결과를 전체 기기 검증으로 표현하지 마세요.

## 참석 응답

- [ ] 하단 참석 버튼이 올바른 폼을 연다.
- [ ] 시크릿 창에서 응답할 수 있다.
- [ ] 제출 완료를 확인했다.
- [ ] 구글시트에 테스트 응답이 저장됐다.
- [ ] 테스트 응답은 삭제했다.

## 공유 범위와 개인정보

- [ ] 사이트에 관리자 키·비밀번호·하객 응답 파일이 없다.
- [ ] 공개 사진·연락처·계좌를 당사자와 확인했다.
- [ ] 링크를 아는 사람은 정보를 볼 수 있음을 이해했다.
- [ ] 검색 제외 설정이 접근 차단을 보장하지 않음을 이해했다.
- [ ] 사이트 접속에 Netlify 로그인이 필요하지 않다.

## 카카오톡 미리보기

내 카카오톡 또는 테스트 대화방에 **최신 기본 주소**를 보내 제목·설명·이미지를 확인합니다. OG 태그는 링크 미리보기의 제목과 그림을 지정하는 정보입니다.

AI에게 다음과 같이 요청할 수 있습니다.

```text
이 청첩장의 카카오톡 공유 미리보기를 설정해줘.
제목: [신랑·신부 결혼합니다]
설명: [예식일·시간·장소]
기본 사이트 주소: [주소]
미리보기 이미지: [배포 가능한 이미지 파일]

정적 HTML의 OG 태그와 실제 공개 이미지 URL을 확인해줘.
링크 크롤러를 막는 robots.txt나 비밀번호 설정을 임의로 추가하지 마.
직접 카카오톡 화면을 확인할 수 없다면 설정 확인과 실제 표시 확인을 구분해줘.
```

예시 코드에 제목·설명이 있어도 OG 이미지·공개 URL까지 완성됐다고 가정하지 마세요. 미리보기가 갱신되지 않으면 캐시일 수 있으므로 최신 URL과 크롤러 접근부터 확인합니다.

## 발송 문구 예시

```text
안녕하세요, [이름]님.
저희가 [날짜]에 결혼합니다.
소중한 날 함께해 주시면 감사하겠습니다.

청첩장: [기본 사이트 주소]
참석 여부는 [마감일]까지 알려주시면 감사하겠습니다.
```

개인화된 `?to=이름` 기능은 현재 템플릿에 구현돼 있지 않습니다. 이름을 붙인다고 자동으로 바뀐다고 안내하지 마세요.
