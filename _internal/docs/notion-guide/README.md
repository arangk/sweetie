# 노션 가이드 초안

이 폴더는 ‘완성 템플릿을 내 사진·정보로 바꿔 배포하는 기본 코스’의 본문 초안입니다. 실제 서비스에 아직 게시하지 않았습니다.

- `00-시작하기.md`: 홈과 전체 목차
- `01`~`08`: 기본 코스
- `09-AI로-디자인-수정.md`: 심화 코스
- `운영자용-공개전-체크리스트.md`: 배포용 템플릿 정리, 미연결 기능, 이용 조건, 캡처·완주 검증

Notion에는 00을 홈으로, 01~09를 하위 페이지로 배치합니다. 운영자 문서는 공개하지 않습니다. 폴더 안의 대괄호 링크·캡처 자리와 편집 메모를 확인한 뒤 채워야 합니다.

현재 코드에 남은 고정 날짜/달력과 RSVP 저장 미연결은 별도 구현 작업입니다. 이 문서 작업에서 애플리케이션을 바꾸거나 공개/배포하지 않았습니다.
