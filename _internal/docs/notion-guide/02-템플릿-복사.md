# 2. 템플릿 복사하기

원본 템플릿은 보존하고, 내 GitHub 계정에 별도 사본을 만들어 작업합니다.

> [템플릿 받기 — 배포용 템플릿 링크 삽입]

## GitHub는 무엇인가요?

청첩장 파일을 보관하고 수정 기록을 남기는 곳입니다. Netlify는 그 파일을 읽어 웹사이트로 배포합니다. GitHub에 저장한 것과 사이트에 게시한 것은 서로 다른 단계입니다.

## 내 사본 만들기

1. GitHub에 가입하거나 로그인합니다.
2. 위 템플릿 링크를 엽니다.
3. 템플릿에서 새 저장소를 만드는 기능을 사용합니다. 실제 버튼명과 화면은 아래 캡처를 참고하세요.
4. 내 계정과 새 저장소 이름을 선택합니다.
5. 개인정보가 들어갈 예정이므로 저장소는 Private으로 만듭니다.
6. 생성된 주소의 소유자가 내 계정인지 확인합니다.

[캡처: 템플릿 버튼 → 새 저장소 생성 → Private → 생성 완료]

공개 템플릿을 그대로 수정하거나, 다른 사람의 저장소에 개인정보를 올리지 마세요. Private 복사가 가능한 배포 경로를 안내자가 사전에 검증한 템플릿을 사용해야 합니다.

## 파일이 있는지 확인하기

최상위 폴더에 다음 파일이 보여야 합니다.

```text
index.html
config.js
app.js
styles.css
assets/
```

README만 보이면 청첩장 파일이 없는 상태입니다. 이 상태로 배포하면 웹페이지가 나오지 않을 수 있습니다.

`index.html`은 첫 화면, `config.js`는 내 정보, `assets`는 사진·폰트가 있는 폴더라고 이해하면 됩니다. GitHub와 Netlify를 연동하는 코스에서는 배포용 ZIP을 따로 올리지 않습니다.

## AI로 수정할 작업 환경 준비

이 자료는 파일을 읽고 수정할 수 있는 AI 작업 환경을 기준으로 합니다. 일반 채팅창은 GitHub의 파일을 직접 고치거나 커밋·푸시하지 못할 수 있습니다.

AI 작업 환경에 내 저장소를 연결하거나 파일을 첨부하세요. 연결할 수 없다면 수정한 파일을 내려받아 GitHub 웹 화면에서 업로드·저장하는 경로를 사용합니다. 구체적인 환경별 화면은 검증된 경로 하나를 선택해 [작업 환경 안내 — 링크 삽입]에 넣습니다.

## 완료 기준

- [ ] 내 계정에 비공개 저장소를 만들었다.
- [ ] 원본과 내 사본의 주소가 다르다.
- [ ] `index.html`과 이미지 폴더가 있다.
- [ ] AI가 내 사본 파일을 읽을 수 있거나 수정 파일을 받을 방법이 있다.
