# sweetie — 나만의 일러스트 모바일 청첩장 템플릿

코딩 몰라도 따라 할 수 있는 모바일 청첩장 템플릿입니다.
겨울 엽서 느낌에, 겹쳐 놓은 사진을 눌러 크게 볼 수 있어요.
**글자와 사진만 바꾸면** 내 청첩장 링크가 생겨요. (개인 청첩장용 무료 공유 템플릿입니다.)

> ⚠️ 들어 있는 일러스트·사진·이름·계좌는 모두 **예시**입니다. 꼭 내 것으로 바꿔 주세요.

## 3단계로 끝

### 1. 내 것으로 복사하기
- **쉬운 방법**: 초록색 **Code** → **Download ZIP** → 압축을 풀어 주세요.
- **GitHub을 쓴다면**: 이 페이지 오른쪽 위 초록색 **Use this template** → **Create a new repository** → 공개 범위는 **Private**을 선택합니다.

폴더 안에 `index.html`, `config.js`, `assets`가 보이면 성공입니다.

### 2. 내용 바꾸기
`config.js` 파일 하나만 열어서 따옴표 안의 글자를 바꿔 주세요. 따옴표와 쉼표는 지우지 마세요.

| 바꿀 것 | config.js의 항목 |
|---|---|
| 신랑·신부 이름 | `names` |
| 예식 날짜·시간 | `date` — 첫 화면·달력·참석 안내·D-day가 함께 바뀝니다 (예: `2027-03-13T12:30:00+09:00`) |
| 예식장 이름·주소 | `venue`, `address` |
| 인사말 | `greeting` (줄바꿈은 `\n`) |
| 마음 전하실 곳(계좌) | `accounts` |
| 오시는 길(지도·교통) | `location` — 정보를 다 넣은 뒤 `ready: true` |
| 참석 여부 링크 | `rsvpUrl` — 구글폼 공유 링크 |
| 참석 폼 질문 | `rsvpFields` — 아래 설명 참고 |
| 사진·일러스트 | `coverImage`, `portraitImage`, `gallery` |
| 갤러리에 보여줄 사진 수 | `galleryCount` |

**사진·일러스트 바꾸기**: 새 파일을 `assets/` 폴더에 넣고 `config.js`에서 아래 경로만 바꿉니다. HTML이나 CSS를 수정할 필요가 없습니다.
- `coverImage`: 표지 카드 이미지. 하단 배경에도 같은 이미지를 사용합니다. 세로 2:3 비율을 추천해요.
- `portraitImage`: 초대 문구 뒤에 깔리는 일러스트.
- `gallery`의 `src`: 갤러리 사진 경로. `caption`은 사진 설명입니다.
- `location.mapImage`: 약도 이미지 경로.

`.png`, `.jpg`, `.webp` 파일을 사용할 수 있습니다. 실제 파일명과 확장자를 정확히 적어 주세요. 빈 경로이거나 파일을 불러오지 못하면 해당 이미지 자리만 숨깁니다. 읽을 수 있는 갤러리 사진만 크게 보기와 넘기기에 포함됩니다.

사진은 가로 1600px 이하로 줄이면 더 빨리 열려요.
일러스트는 ChatGPT에 사진을 올려서 만드는 걸 추천합니다.

**갤러리 사진 수와 참석 폼 질문 정하기**

```js
galleryCount: 4, // 갤러리에 보여줄 사진 수
rsvpFields: ['하객 구분', '참석 여부', '식사 여부', '성함', '동행인 수'], // 기본값
```

- 사진을 더 넣고 싶다면 `gallery` 목록에도 사진을 추가해 주세요. 6장을 넘으면 사진이 아래로 이어져요.
- 참석 여부만 받고 싶다면 `rsvpFields: ['참석 여부']`처럼 필요한 항목만 남깁니다.
- 지운 항목은 화면에서 사라지고, 필수 입력 검사에서도 빠져요.

### 3. 내 청첩장 주소 만들기
내 청첩장 주소는 **Netlify**나 **Cloudflare** 중 한 곳에서 만들 수 있어요. 사이트를 인터넷에 올려 두는 곳을 호스팅이라고 해요.
둘 다 무료로 시작할 수 있고, 차이는 새로 올릴 수 있는 횟수입니다. (Netlify 한 달 약 20번, Cloudflare 500번)

- **ZIP으로 받았다면**: Netlify에서 새 사이트를 만들고 `index.html`이 바로 보이는 폴더를 끌어다 놓습니다.
- **GitHub을 쓴다면**: Netlify 또는 Cloudflare에서 내 저장소를 연결합니다.

**고칠 때마다 올리지 말고**, 컴퓨터에서 `index.html`을 더블클릭해 열어 확인한 뒤 마지막에 한 번만 올려 주세요.
올린 뒤에는 **꼭 휴대폰으로** 확인해 주세요. 글씨체, 갤러리 사진 확대, 참석 버튼, 링크 미리보기를 보면 됩니다.

디자인이나 구성을 더 바꾸고 싶다면 Claude Code나 Codex에게 요청해 보세요.

## 개인정보 주의
- 이 사이트는 검색에 나오지 않도록(`noindex`) 설정되어 있지만, **링크를 아는 사람은 누구나** 볼 수 있어요. 하객에게만 보내 주세요.
- 집 주소, 주민번호는 넣지 마세요.
- 참석 여부는 **구글폼 링크**로 받는 것을 권장합니다. 수집 목적과 삭제 날짜를 폼에 안내하고, 예식 후 응답을 삭제해 주세요.

## 폰트
Orbit, Parisienne, 나눔손글씨(Daughter To Mom)는 `assets/fonts/`에 포함되어 있고, Noto Serif KR·Cormorant Garamond는 Google Fonts에서 불러옵니다. 각 폰트의 라이선스는 폰트 폴더의 `*-OFL.txt` 및 제공처 안내를 확인해 주세요.

## 사용 조건
개인 청첩장 용도로 자유롭게 수정해 쓸 수 있습니다. 템플릿 자체의 재판매·유료 배포는 하지 말아 주세요.
예시 일러스트와 사진은 AI로 생성한 이미지입니다. 내 이미지를 AI로 만들었다면 청첩장에 "AI 생성" 표기를 남겨 주세요.
