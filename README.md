# sweetie — 나만의 일러스트 모바일 청첩장 템플릿

겨울 엽서 느낌의 모바일 청첩장입니다. 카드를 눌러 뒤집고, 겹친 사진을 눌러 크게 볼 수 있어요.
개발을 몰라도 **글자와 사진만 바꾸면** 내 청첩장이 됩니다. (개인 청첩장용 무료 공유 템플릿이에요.)

> ⚠️ 들어 있는 일러스트·사진·이름·계좌는 모두 **예시**입니다. 꼭 내 것으로 바꿔 주세요.

## 3단계로 끝

### 1. 내 것으로 복사하기
- **GitHub을 쓴다면**: 이 페이지 오른쪽 위 초록색 **Use this template** → **Create a new repository** → 공개 범위는 **Private** 선택
- **GitHub이 처음이면**: **Code → Download ZIP** 으로 받아서 압축을 풀어 주세요.

### 2. 내용 바꾸기
**`config.js` 파일 하나만** 열어서 따옴표 안의 글자를 바꿉니다.

| 바꿀 것 | config.js의 항목 |
|---|---|
| 신랑·신부 이름 | `names` |
| 예식 날짜·시간 | `date` — 첫 화면·달력·참석 안내·D-day가 함께 바뀝니다 (예: `2027-03-13T12:30:00+09:00`) |
| 예식장 이름·주소 | `venue`, `address` |
| 인사말 | `greeting` (줄바꿈은 `\n`) |
| 마음 전하실 곳(계좌) | `accounts` |
| 오시는 길(지도·교통) | `location` — 정보를 다 넣은 뒤 `ready: true` |
| 표시할 사진 수 | `galleryCount` — 예: `3`이면 최대 3장, `0`이면 숨김 |
| 참석 입력 항목 | `rsvpFields` — 예: `['참석 여부', '전세버스 이용 여부']` |
| 참석 여부 링크 | `rsvpUrl` — 구글폼 공유 링크 |

**사진·일러스트 바꾸기**: 새 파일을 `assets/` 폴더에 넣고 `config.js`에서 아래 경로만 바꿉니다. HTML이나 CSS를 수정할 필요가 없습니다.
- `coverImage`: 표지 카드 이미지. 하단 배경에도 같은 이미지를 사용합니다. 세로 2:3 비율 추천.
- `portraitImage`: 초대 문구 뒤에 깔리는 일러스트.
- `gallery`의 `src`: 갤러리 사진 경로. `caption`은 사진 설명입니다.
- `location.mapImage`: 약도 이미지 경로.

`galleryCount`보다 사진이 부족하면 정상 사진까지만 표시합니다. 사진을 7장 이상 넣으면 콜라주가 아래로 확장됩니다.

`.png`, `.jpg`, `.webp` 파일을 사용할 수 있습니다. 실제 파일명과 확장자를 정확히 적어 주세요. 빈 경로이거나 파일을 불러오지 못하면 해당 이미지 자리만 숨깁니다. 읽을 수 있는 갤러리 사진만 크게 보기와 넘기기에 포함됩니다.

> 사진은 가로 1600px 이하로 줄이고, 위치 정보(EXIF)가 없는 파일을 쓰세요. 원본을 그대로 올리지 마세요.

### 3. 인터넷에 올리기 (배포)
- **ZIP으로 받은 경우**: Netlify에서 폴더를 끌어다 놓아 올릴 수 있어요. *(메뉴 이름은 바뀔 수 있어 가이드 자료의 캡처를 따라 주세요)*
- **GitHub을 쓰는 경우**: Netlify 또는 Cloudflare Pages에서 내 저장소를 연결합니다. 저장소가 Private이어도 사이트는 공개됩니다.
- 올린 뒤 **꼭 휴대폰으로** 확인하세요: 카드 뒤집기, 갤러리 탭 확대, 글씨 줄바꿈, 링크 미리보기.

## 개인정보 주의
- 이 사이트는 검색에 나오지 않도록(`noindex`) 설정되어 있지만, **링크를 아는 사람은 누구나** 볼 수 있어요. 필요한 정보만 넣으세요.
- 참석 여부는 **구글폼 링크**로 받는 것을 권장합니다. 수집 목적·보관 기간을 폼에 안내하고, 예식 후 응답을 삭제하세요.
- 사이트 안의 참석 입력 화면은 **미리보기**이며 실제로 전달되지 않습니다. `rsvpFields`에 적은 항목만 나오며, 외부 구글폼의 질문은 구글폼에서 별도로 설정해야 합니다.

## 폰트
Orbit, Parisienne, Cormorant Garamond, 나눔손글씨(Daughter To Mom)는 로컬 폰트로 제공됩니다. 영문 타이틀 폰트는 HTML에 포함해 바로 읽고, 기본 초대글은 작은 글꼴 파일을 사용합니다. 다른 문구에 필요한 글자는 원본 폰트에서 불러옵니다. 각 폰트의 라이선스는 폰트 폴더의 `*-OFL.txt` 및 제공처 안내를 확인하세요.

## 사용 조건
개인 청첩장 용도로 자유롭게 수정해 쓸 수 있습니다. 템플릿 자체의 재판매·유료 배포는 하지 마세요.
예시 일러스트와 사진은 AI로 생성한 이미지입니다. 내 이미지를 AI로 만들었다면 청첩장에 "AI 생성" 표기를 남겨 주세요.
